# fgof 0.2-2

## Compatibility

- Declare author roles through `Authors@R` and correct DESCRIPTION title case,
  as requested by current incoming checks. Authorship and the maintainer
  address are unchanged.

- Normalize `simulation` and `qgrid` choices before scalar conditions, restoring
  their documented defaults on current R. Invalid choices now report an error.
- Import functions used from stats, mvtnorm, and numDeriv so namespace-only calls
  work without attaching dependency packages.
- Exclude recovery records and development files from source package builds.
- Remove the recovered tarball's generated MD5 manifest from the maintained
  source tree; package builds generate a fresh manifest.
- Add fixed-seed regression tests using testthat as a suggested test dependency,
  with a separate base R check for namespace isolation. No runtime dependency
  was added.
- Update release metadata for revival after archival on 2022-04-27, and remove
  fields generated by the previous CRAN build.
- Reduce example simulation counts for routine checks; retain larger calibration
  studies outside the distributed package.

## Correctness

- Check default multiplier-bootstrap derivatives for both standard and
  user-defined distributions. Infer parameter scales from log-density changes
  or reuse supplied optimizer scales; cap steps relative to those scales and
  tested feasible radii. Check independently selected score and CDF steps for
  stability and floating-point resolution, retaining the Richardson method.
- Preserve explicitly supplied `method.args`, analytical derivative callbacks,
  the parametric bootstrap, and the public function signature and return layout.
  Numerical functions that are noisy, domain-limited, or unstable can now produce
  actionable derivative errors instead of unchecked results. The score
  covariance and influence-matrix formulas are unchanged.

- Use `(count + 0.5) / (nsim + 1)` for bootstrap p-values, as specified by the
  maintainer. This keeps p-values strictly between zero and one and changes
  the archived p-values by `0.5 / (nsim + 1)` without changing bootstrap draws,
  observed statistics, or parameter estimates.
- Preserve parameter names and fixed distribution arguments during fitting,
  CDF/density evaluation, quantile-grid construction, and bootstrap simulation.
  In particular, gamma scale parameters are no longer interpreted as rates.
- Evaluate analytical CDF derivatives at the requested grid points, and validate
  callback dimensions before matrix operations.
- Align parametric-bootstrap statistic and p-value labels with the observed
  statistics, retaining the returned list and matrix structure.
- Replace the unavailable `mecdf` call with direct empirical lower-orthant counts,
  using the empirical CDF definition in the original paper and no new dependency.
- Report invalid inputs and singular score covariance matrices more clearly.
  Optimizer defaults, covariance normalization, centering, and test statistics
  are unchanged.
